# 🚛 שרת מקומי — חיבור וואטסאפ ב-QR + נועה 🤖

## 🧰 התקנה
```bash
cd local-server
npm install
npm start
```

## 📱 חיבור
1. הרצה ראשונה מציגה **QR** בטרמינל, וגם ב־`http://localhost:8787/qr`
2. בנייד: וואטסאפ ← הגדרות ← **מכשירים מקושרים** ← קישור מכשיר ← סריקה
3. ההתחברות נשמרת בתיקייה `.wwebjs_auth` (אין צורך לסרוק שוב)

## ⚙️ משתני סביבה
| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `PORT` | `8787` | פורט השרת המקומי |
| `APP_URL` | `http://localhost:8080` | כתובת האפליקציה לסנכרון הודעות למסך |
| `REPORT_TARGET` | – | יעד דו"ח הבוקר, למשל `972501234567@c.us` או מזהה קבוצה |
| `AUTO_REPLY` | `true` | מענה אוטומטי ללקוחות |

דוגמה:
```bash
APP_URL=https://sidor-noa.lovable.app REPORT_TARGET=972501234567@c.us npm start
```

## 🔌 נקודות קצה
| שיטה | נתיב | תיאור |
|---|---|---|
| GET | `/status` | מצב החיבור 🔎 |
| GET | `/qr` | דף סריקת QR 📱 |
| GET | `/orders` | כל ההזמנות שנקלטו 📦 |
| POST | `/send` | `{ "phone": "0501234567", "text": "..." }` ✉️ |
| POST | `/report` | שליחת דו"ח בוקר ידנית 📅 |

## 🧠 noaBrain.js
- `respond(text, meta)` — 💬 מענה אוטומטי לפי כוונה (ברכה, מחיר, סטטוס, ביטול, הזמנה)
- `normalizeOrder(text, meta)` — 📦 נרמול הזמנה: חומר, כמות, יחידה, כתובת, תאריך, שעה, דחיפות, שדות חסרים
- `buildMorningReport(orders)` — 📅 דו"ח בוקר מעוצב בוואטסאפ (מודגש + אימוג'ים)
- `normalizePhone` / `toChatId` — ☎️ נרמול מספרים ישראליים

## ⏰ דו"ח בוקר
נשלח אוטומטית כל יום ב־**06:30** שעון ירושלים ל־`REPORT_TARGET`.
